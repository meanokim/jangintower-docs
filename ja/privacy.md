# 職人の塔 プライバシーポリシー

김민영(以下「開発者」)は、モバイルゲーム「職人の塔」(以下「本ゲーム」)を提供するにあたり、利用者の個人情報を大切に取り扱います。本ポリシーでは、本ゲームがどのような情報をなぜ取り扱うのか、利用者にどのような権利があるのかをご案内します。本日本語版と[韓国語の原文](../privacy)に違いがある場合は、韓国語の原文が優先されます。

## 1. 会員登録と直接取得する情報

本ゲームには会員登録がなく、氏名・電話番号・メールアドレスなどの入力を求めることはありません。ゲームの進行データは基本的に利用者の端末内にのみ保存されます。

ただし、**塔ランキング**に参加する場合(初期設定で参加、設定でオフにできます)、次の情報をサーバー(Google Firebase、ソウルリージョン)に保存します。

| 項目 | 目的 |
| --- | --- |
| 匿名ユーザーID(Firebase 匿名認証) | ランキング記録と週間報酬メールを利用者ごとに区別するため |
| ニックネーム(利用者が決めた名前、または自動の名前「장인XXXX」) | ランキング一覧への表示 |
| 塔の進行記録(到達したステージ・階、到達時刻、記録更新時刻) | 順位の計算、不正記録の検査 |
| 週間報酬メール(順位、報酬内容、受け取り状況) | 毎週の順位報酬の付与 |

ニックネームと塔の進行記録は、ランキング一覧として他の利用者に公開されます。

## 2. 自動的に取り扱われる情報

| 項目 | 目的 | 取り扱う事業者 |
| --- | --- | --- |
| 広告識別子(IDFA・広告ID)、端末情報(機種、OSバージョン、言語)、IPアドレス、広告の操作情報 | 広告の表示と効果測定、不正クリックの防止 | Google AdMob |
| アプリの利用記録(階のクリア、強化の試行などのゲームイベント)、アプリインスタンスID、端末情報 | ゲーム改善とバランス調整のための統計 | Google Firebase Analytics |
| クラッシュ記録(エラー内容、端末・OS情報) | 不具合の修正と安定性の向上 | Google Firebase Crashlytics |
| 購入履歴(商品、取引番号) | 有料商品の付与と購入の復元 | Apple App Store、Google Play |
| Game Center・Google Play ゲームズのアカウント識別子、クラウド保存データ | 実績、端末間でのデータ移行 | Apple、Google |

- 支払い手段の情報(カード番号など)は各ストアが取り扱い、開発者は受け取りません。
- iOSでは、まずアプリのトラッキング透明性(ATT)の許可を確認し、許可されない場合は広告識別子を使用しません。
- 欧州経済領域・英国などでは、Googleの同意管理プラットフォーム(UMP)で広告のプライバシーに関する同意をいただきます。ゲームの**設定 → 広告のプライバシー設定**からいつでも変更できます。

## 3. 保存期間

- ランキング記録・ニックネーム・報酬メール: 利用者が**設定 → ランキング記録の削除**を押すと直ちに削除されます。それまではランキングの運営期間中保存します。
- 端末に保存されたゲームデータ: アプリを削除すると一緒に削除されます。
- Firebase Analytics のデータ: 取得日から最長14か月保存した後に削除されます。
- Crashlytics のデータ: 取得日から最長90日保存した後に削除されます。
- 広告・決済・ゲームサービスの情報: 各提供者(Google、Apple)のポリシーに従います。

## 4. 第三者提供と取り扱いの委託

開発者は利用者の情報を販売しません。上記2項のサービス提供者にのみ、その目的の範囲内で取り扱いを委託します。各提供者は外国(米国など)にサーバーを置いている場合があります。

- Google プライバシーポリシー: https://policies.google.com/privacy
- Google によるパートナーアプリの情報の使用: https://policies.google.com/technologies/partner-sites
- Apple プライバシーポリシー: https://www.apple.com/jp/legal/privacy/

## 5. 利用者の権利

- 広告トラッキングの拒否: iOS **設定 → プライバシーとセキュリティ → トラッキング**、Android **設定 → プライバシー → 広告**から変更できます。
- ランキング参加のオフ・記録の削除: ゲームの**設定 → ランキング参加 / ランキング記録の削除**からいつでもできます。削除すると、サーバーの匿名ID・ニックネーム・ランキング記録・報酬メールがすべて消去されます。
- ゲームデータの削除: アプリを削除すると端末のデータが削除されます。クラウド保存データは Game Center・Google Play ゲームズの設定から削除できます。
- その他の開示・訂正・削除のご依頼は、下記の連絡先までお送りください。

## 6. 子どもの個人情報

本ゲームは14歳未満の子どもを対象としておらず、子どもの個人情報を故意に取得することはありません。
